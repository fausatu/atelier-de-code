# Logos des parcours

Dépose ici un fichier par parcours, nommé avec l'identifiant du parcours :

| Parcours | Fichier attendu |
|---|---|
| PHP orienté objet | `php.svg` (ou `php.png`) |
| Doctrine ORM | `doctrine.svg` |
| DTO avec Symfony | `dto.svg` |
| Architecture | `arch.svg` |
| DDD | `ddd.svg` |
| React | `react.svg` |
| React : données & API | `data.svg` |
| Next.js | `next.svg` |
| Git & GitHub | `git.svg` |

- SVG de préférence (net à toutes les tailles), sinon PNG carré d'au moins 128 px.
- Si le fichier manque, le dashboard affiche un badge texte à la place.
- Aucune modification du code n'est nécessaire : la page cherche `logos/<id>.svg` puis `logos/<id>.png`.
